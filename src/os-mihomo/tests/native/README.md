# Native checks

The VNET jail harness uses the installed package's genuine Core configuration
and BaseModel framework against a private `/conf/config.xml` generated by its
test case. `prepare.sh` selects only package-owned MVC PHP/XML files and PHP
modules, generates its own PHP configuration, and excludes host configuration,
credentials, bytecode and caches. It retains synthetic `util.inc`, configuration
revision, `configctl`, service, PF and template adapters. Its lifecycle attestation
does not prove host PF, template or LAN integration.

The package lifecycle case distinguishes reinstall with a retained XML backup
from installation without one. It erases private application stores and verifies
that the retained backup restores administrative Stop, then removes only the
private XML's Mihomo backup node and erases the stores again to verify fresh
proxy-port defaults. Other XML nodes remain in place.

These adapters mean a script that calls a function the real OPNsense tree defines
elsewhere passes there and fails on a router. `setup_unbound.php` did exactly
that: it required `config.inc` alone, and `config.inc` reaches for
`shell_safe()` from `util.inc` when it stamps a configuration revision, so
every write failed the moment it was attempted on a real system.

`check-undefined.php` resolves every function each CLI entry point calls after
that entry point's own includes have run. Run it on the target:

```sh
php src/os-mihomo/tests/native/check-undefined.php
```

It needs the real tree and therefore cannot run in CI or on the build host.
