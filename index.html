Mihomo for OPNsense

Mihomo 1.1.3 is maintained for OPNsense CE 26.7 / FreeBSD:15:amd64; legacy downloads for FreeBSD 14 and 15 are retained. Installation and legacy migration run local proxy ports. Later upgrades and reinstalls preserve explicit transparent activation and administrative Stop. Packages and catalogs are signed with the existing RSA key.

Source code · Public key · Repository configuration · Checksums

Install the repository

Run once on each OPNsense router. Verify the public key fingerprint before enabling the repository.

fetch -o /tmp/kazuha-bootstrap.sh \
  https://kkazuhak.github.io/OPNsense-repo/client.sh
sh /tmp/kazuha-bootstrap.sh

Install and configure the plugin

Install os-kazuha-repo from System → Firmware → Plugins to keep the signed repository configured across firmware updates, then install os-mihomo. The repository bootstrap script verifies the trust anchor and catalog before installing only the repository plugin. Perform gateway plugin migration in a maintenance window. Open VPN → Proxy Suite → Mihomo Subscribe, save the full YAML subscription URL and this router's dashboard address, and fetch the subscription.

Local proxy ports are 127.0.0.1:7890 (mixed) and 127.0.0.1:7891 (SOCKS5). Use Enable transparent routing on the Mihomo page to activate TUN and DNS together. DNS falls back to the original router configuration after a core crash by default; this policy can be changed per router.

Trust anchor

Before a firmware upgrade, download check-upgrade.py and verify-repo.py into the same directory, then run python3 check-upgrade.py --abi TARGET_ABI --product-abi TARGET_SERIES with the officially announced values. Every published target requires native testing. The next 27.1 base is not yet announced; FreeBSD 16 support is not claimed. See the release checklist.
